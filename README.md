# 🧳 ระบบวิเคราะห์ข้อความจองทริปท่องเที่ยว (Trip Booking Text Analyzer)

Web Application ที่ใช้ประมวลผลข้อความภาษาไทยเกี่ยวกับการจอง/วางแผนทริปท่องเที่ยว
เพื่อสกัดข้อมูลสำคัญ ได้แก่ **สถานที่เที่ยว, โรงแรม/ที่พัก, จำนวนวัน-คืน, และงบประมาณ**
โดยพัฒนาด้วย [Streamlit](https://streamlit.io) และ [PyThaiNLP](https://pythainlp.org)

## แนวคิดของ Domain

ผู้ใช้งาน (เช่น แอดมินเพจท่องเที่ยว หรือแอปวางแผนทริป) มักได้รับข้อความจากลูกค้าในรูปแบบ
อิสระ ไม่มีโครงสร้างตายตัว เช่น แชท หรือรีวิว การให้ระบบช่วยสกัดข้อมูลสำคัญโดยอัตโนมัติ
จะช่วยลดเวลาในการอ่านและจัดหมวดหมู่ข้อมูลด้วยมือ

## เทคนิค NLP ที่ใช้

| เทคนิค | การใช้งานในระบบ |
|---|---|
| **Regex & Cleansing** | ลบลิงก์และเบอร์โทรศัพท์ที่ไม่เกี่ยวข้อง, ดึงจำนวนวัน/คืนด้วย pattern เช่น `(\d+)\s*(วัน\|คืน)` |
| **Tokenization** | ตัดคำภาษาไทยด้วย `pythainlp.tokenize.word_tokenize` (engine `newmm`) |
| **POS Tagging** | กำหนดชนิดคำด้วย `pythainlp.tag.pos_tag` (Universal POS tagset) เพื่อดูโครงสร้างประโยค |
| **Named Entity Recognition (NER)** | ใช้โมเดล `thainer` ของ PyThaiNLP สกัด entity ประเภท `LOCATION` (สถานที่/โรงแรม), `MONEY` (งบประมาณ) แล้วจัดหมวดต่อด้วย keyword เช่น "โรงแรม", "รีสอร์ท" เพื่อแยกโรงแรมออกจากสถานที่เที่ยวทั่วไป |

## วิธีใช้งาน

1. เปิดหน้าเว็บ (ดู URL ด้านล่าง หรือรันในเครื่องตัวเอง)
2. พิมพ์หรือวางข้อความจองทริป/รีวิวทริปท่องเที่ยว หรือกดปุ่มตัวอย่างในแถบด้านซ้าย
3. กดปุ่ม **"วิเคราะห์ข้อความ"**
4. ดูผลลัพธ์: สถานที่เที่ยว, โรงแรม, งบประมาณ, จำนวนวัน/คืน พร้อมตาราง POS และ NER แบบละเอียด

## การติดตั้งและรันในเครื่อง (Local)

```bash
git clone <ลิงก์ repo ของคุณ>
cd <ชื่อโฟลเดอร์>
pip install -r requirements.txt
streamlit run app.py
```

> หมายเหตุ: การโหลดโมเดล NER (`thainer`) ครั้งแรกจะใช้เวลาสักครู่เพื่อดาวน์โหลดโมเดล

## ตัวอย่าง Prompt ที่ใช้สั่ง AI ช่วยพัฒนา

```
ช่วยเขียน Streamlit web app ภาษาไทยสำหรับวิเคราะห์ข้อความจองทริปท่องเที่ยว
โดยใช้ pythainlp ทำ tokenization, POS tagging และ NER (thainer)
เพื่อสกัดสถานที่เที่ยว โรงแรม งบประมาณ และจำนวนวัน-คืน
ให้มีตัวอย่างข้อความให้กดทดลอง และแสดงผลลัพธ์ POS/NER แบบตาราง
```

## Deploy บน Streamlit Community Cloud

1. Push โค้ดทั้งหมดขึ้น GitHub Repository (public)
2. เข้า https://share.streamlit.io และ Sign in ด้วย GitHub
3. กด "New app" เลือก repository, branch และไฟล์ `app.py`
4. กด "Deploy" แล้วรอสักครู่จะได้ URL หน้าเว็บที่ใช้งานได้จริง
